# 02　章节骨架与版式

---

## 1. 三种骨架，先选对

### A. 验证性实验 —— 六章（最常用）

| 章 | 标题 | 内容要点 | 表格 |
|---|---|---|---|
| 一 | 实验目的 | 原文 1~3 条，动词：掌握/熟悉/了解 | 0 |
| 二 | 实验原理 | 困难 → 办法 → 公式推导；含干扰排除机制 | 0 |
| 三 | 实验仪器与试剂 | 文字列举（仪器、试剂与试液、配制） | 0 |
| 四 | 实验方法 | 按操作顺序编号 | 0 |
| 五 | 数据记录、计算与判定 | （一）原始数据记录（三线表逐格转录）（二）计算过程（文字）（三）判定（含限度） | 1~2 |
| 六 | 讨论与思考题 | 结果讨论 + 思考题逐条作答 | 0 |

**这是"精简版"结构，建议新报告直接按此起手。**
很多初稿会写成"仪器表 + 试剂表 + 操作流程表 + 符号表 + 计算过程表 + 结果表"共六七张表，
批改后通常被要求删到 1~2 张——**表格只留给"一手数据"**，其余用文字。

### B. 方法学考察型 —— 八章

| 章 | 标题 | 内容要点 | 表格 |
|---|---|---|---|
| 一 | 实验目的 | 方法建立 + 方法学评价 | 0 |
| 二 | 实验原理 | 分离/测定机理、定量式 | 0 |
| 三 | 实验仪器与材料 | 仪器、条件（色谱/光学）、试药与试液 | 0 |
| 四 | 实验内容 | 溶液制备 + **方法学考察方案**（线性/精密度/稳定性/重复性） | 若干 |
| 五 | 数据处理与计算 | 逐项给计算式与代入过程 + 结果汇总表 | 4~8 |
| 六 | 结果与讨论 | ★ 逐项讨论达标与否 + 一致性诊断 + 复核路径 | 0~1 |
| 七 | 思考题 | 逐条作答 | 0 |
| 八 | 结论 | 几项达标、含量结果、总体判定 | 0 |

**分量在五、六两章**：第五章把"怎么算出来的"摊开，第六章回答"为什么是这个结果、可不可信、怎么复核"。

### C. 工艺/处方筛选型 —— 六章 + 极差/方差分析

在 B 的骨架上，第五章增加"极差分析"与"方差分析"两节；第六章给最优水平与因素主次。

## 2. 每章该写多少

经验值（中文 A4，正文 10.5~12 pt）：

| 章 | 篇幅 | 常见毛病 |
|---|---|---|
| 目的 | 3~6 行 | 把原理抄进目的 |
| 原理 | 1~2 页 | 只抄公式、不说"为什么能排除干扰" |
| 仪器试剂 | 5~10 行 | 做成大表，一页只有几行信息 |
| 方法 | 1~2 页 | 漏写"定容到多少""取几份" |
| 数据与计算 | 2~4 页 | 只给结果、不给代入过程 |
| 讨论与思考题 | 1~2 页 | 思考题答成教科书通论，不结合本组数据 |

## 3. 版式参数（两套常见模板，选一套并全程一致）

### 紧凑型（信息密度高，页数少）

| 项目 | 规范 |
|---|---|
| 页面 | A4（21.0 × 29.7 cm），边距 **上/下 2.0 cm、左/右 1.5 cm** |
| 正文 | 中文宋体 + 西文 Times New Roman，**10.5 pt**，行距 **1.28**，首行缩进 **21 pt**，两端对齐 |
| 一级标题 | 黑体 **12.5 pt** 加粗，深蓝 `#1F3864`，段前 12 pt / 段后 6 pt，与下段同页 |
| 二级标题 | 黑体 11 pt 加粗深蓝，段前 8 / 段后 4 |
| 三级标题 | 楷体 10.5 pt 加粗，段前 5 / 段后 3 |
| 注 | 楷体 9.5 pt，灰 `#444444`，左缩进 12 pt，行距 1.15 |
| 表题 / 图题 | 宋体 9.5 pt 加粗居中，**置于表格上方**，与表同页；编号 `表 N　…`（**全角空格**） |
| 表格 | 三线表，表内 9 pt 水平+垂直居中 |

### 宽松型（学院模板风格，留白多）

| 项目 | 规范 |
|---|---|
| 页面 | A4，边距 **上/下 2.54 cm、左/右 3.17 cm** |
| 正文 | 中文宋体 + 西文 Times New Roman，**12 pt**，行距 **1.5**，首行缩进 **24 pt**，两端对齐 |
| 大标题 | 黑体 16 pt 加粗居中 |
| 一级标题 | 黑体 **14 pt** 加粗 |
| 二级标题 | 黑体 12 pt 加粗 |
| 表题 / 图题 | 黑体 **10.5 pt** 加粗居中，`表 N　…` / `图 N　…` |
| 表注 | 楷体 9.5 pt 灰 `#444444` |
| 表格 | 三线表，表内 10.5 pt 居中 |

> **开工前先确认用哪套**。混用（正文 10.5 pt 却配 1.5 倍行距、表内 9 pt 配 12 pt 正文）
> 是最常见的"看起来不对劲"来源。

### 三线表的具体做法（两套通用）

```
顶线：1.5 pt（单线）
表头下：0.75 pt（单线）
底线：1.5 pt
无左右竖线、无内部横线
```

在 `python-docx` 里对应 `sz=12` / `sz=6` / `sz=12`（单位 1/8 pt）。
`scripts/docx_builder.py` 的 `add_table()` 已封装好，直接用。

## 4. 什么时候用表，什么时候用文字

| 内容 | 形式 | 理由 |
|---|---|---|
| 原始读数（吸光度、滴定体积、峰面积、观察结果） | **三线表逐格转录** | 一手数据要可核对 |
| 仪器 / 试剂清单 | **文字列举** | 表格占版面、信息密度低 |
| 计算过程 | **文字说明**（公式 + 代入） | 表格反而看不清推导 |
| 判定 | **文字说明**（含限度原文） | 判定是一句话，不需要表 |
| 方法学汇总（多项并列） | **表**（项目/指标/判据/判定） | 五项以上并列时表最清楚 |
| 正交 K 值、方差分析 | **表** | 矩阵型数据 |

表的编号在全文**连续**；删表后必须**重排编号**（删了表 3，原表 4 要变成表 3）。

## 5. Excel 工作簿的组织

四张表是惯例（方法学项目多的可扩到 6~8 张）：

| 表 | 内容 |
|---|---|
| **使用说明** | 数据流、怎么换数、本组结论 |
| **数据输入** | 原始读数，**待填格用浅黄底**标出 |
| **计算** | 全公式（引用数据输入，不硬编码结果） |
| **公式与依据** | 原理、符号说明、限度依据、操作要点 |

规范：

- 表头浅灰填充、大标题深蓝 14 pt、节标题 11 pt、注 9 pt 灰、警示红
- 长文本格 `wrap_text=True`，并**按「文本宽度 ÷ 列宽」估算行数后显式设置行高**
  （Excel 不会自动撑开合并单元格，不设就会截断长句）
- 峰面积等大整数用整数格式（`0.0` 会显示成 `150278.0`）
- **不要把说明文字写在以 `=` 开头的格子里**——会被当公式，打开就是 `#NAME?`
- 打印设置为 A4 横向、按宽度缩放

## 6. 批注与插图

- **至少留 1 条批注**，交代本次的口径判断（为什么用这个波长、为什么剔除某个点、
  为什么只有一组数据）。批注是给批改人和未来的自己看的。
- 插图（标准曲线、稳定性趋势）优先**程序化绘制**（matplotlib，或 Pillow 手绘），
  保证换数据后能一键重画；不要手工截图贴进去。
- 要插原始谱图/实物照片时，先确认是否必要——多数情况下曲线图比截图更清楚。
