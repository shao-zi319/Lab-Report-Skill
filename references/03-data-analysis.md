## 0. 通用统计工具

```python
def mean(xs): return sum(xs) / len(xs)

def sd(xs):                      # 样本标准差，分母 n−1
    n = len(xs)
    if n < 2: return None        # ★ 不编造数值
    m = mean(xs)
    return math.sqrt(sum((x - m) ** 2 for x in xs) / (n - 1))

def rsd(xs):                     # 相对标准偏差 %
    s = sd(xs)
    return None if s is None else s / mean(xs) * 100.0
```

**★ `n < 2` 一律返回 `None`，正文显示「—」。**
只测了一份就是不能报精密度，这不是数据缺失，是事实。

**最小二乘回归**（线性关系用）：

```
slope     = Sxy / Sxx
intercept = ȳ − slope·x̄
r         = Sxy / √(Sxx·Syy)
s_b       = √( Σ(y − ŷ)² / (n−2) / Sxx )      斜率标准误
相对偏差% = (y − ŷ) / ŷ × 100%                 逐点残差，用来找离群点
```

## 1. 限量检查（只判超限，不测含量）

```
L(%) = V · c / S × 100%
```

- `V` = 标准溶液体积（mL），`c` = 标准溶液浓度（μg/mL），`S` = 取样量（g）
- ★ **`V·c` 得 μg、`S` 得 g，必须统一到 μg 再相除**（1 g = 10⁶ μg）。差一个量级就是 10⁶ 倍的错。

示例（氯化物检查，取样 0.30 g、标准液 3.0 mL × 10 μg/mL）：

```
L = 3.0 × 10 / (0.30 × 10⁶) × 100% = 0.010%     与药典限度 0.010% 一致
```

**判定与观察结果解耦**：限量本身是确定性计算（与是否实测无关）；
观察结果只决定"符不符合规定"。把观察结果做成布尔量：

```python
OBS_PASS = True          # True = 供试品管不深于对照管
DATA_OBS_FILLED = True   # False → 全文显示「（待填）」，不代填
```

判定推演（比浊）：`A 管浊度 ＞ B 管` ⟹ B 不深于 A ⟹ 未超限量 ⟹ **符合规定**。

## 2. 外标一点法（色谱、紫外，最常用）

```
C样 = C对 × A样 ÷ A对
m   = C样 × V                         V = 供试品溶液定容体积
含量(占标示量%) = m ÷ 相当量 × 100%
每片含量(mg) = 含量% ÷ 100 × 标示量
```

等价写法：`含量% = C样 ÷ C理 × 100%`（`C理 = 相当量 ÷ V`）。
两种写法结果相同，**任选一种并写清用哪种**，不要混着写。

易错点：

- ★ 外标法要求对照品与供试品**同体积进样**（同体积时峰面积比与进样体积无关）
- ⚠️ 把"总片重 ÷ 称样量"当作"相当量"、或漏乘/漏除定容体积 → 结果成倍偏差
- "相当量"是**称样量中约相当于主药的量**，不是片重、不是称样量本身

## 3. 对照品比较法（紫外，通式）

```
含量(mg/片) = ΔA_X × m_R × W̄ ÷ (ΔA_R × W)
占标示量%   = 含量 ÷ 标示量 × 100%
```

- `m_R` = **相当于对照品的质量** = `c_R × V_瓶`。
  若对照品浓度已按原料药含量折算（如按 95% 计），**取折算后的量**，不是称取量。
- `W̄` = 平均片重，`W` = 供试品称取量；`W̄/W` 起"折算到每片"的作用。
- 供试品与对照品**同倍数稀释**时，稀释倍数在比值中约去——但仍要在报告里写出，便于核对。

---

## 4. 双波长等吸收点法（复方制剂两组分同时定量）

```
ΔA = A_λ2 − A_λ1        λ2 = 测定波长，λ1 = 参比（等吸收点）波长
ΔA = ΔE · C · l         干扰组分在 λ1/λ2 吸光度相等 ⟹ 其 ΔA = 0
```

口径要点：

1. **λ1/λ2 的命名以课件为准**（λ2 = 测定波长）。手写记录常标反——
   按课件口径，数值不受影响（只是符号顺序），但**必须加批注说明**。
2. 等吸收点的验证：测定 A 组分时，B 组分对照液在 λ1/λ2 的 ΔA 应 ≈ 0。
3. 平行性用**相对平均偏差**：`|a−b| / 平均值 × 100%`。
   光度法常规要求 ≤ 2%；超了就在判定里写"单份超限、平行性不足、**建议复测**"，
   不要只用一个平均值宣布过关。

## 5. 滴定法（两步滴定，酯类药物的经典做法）

```
含量(%) = (V⁰ − Vˢ) × F(回滴液) × T(水解用碱) × W̄ / (W × B) × 100%
T = 2 × c(酸) × M(被测物)        例：2 × 0.05 mmol/mL × 180.16 = 18.02 mg/mL
```

**两个必须先想明白的口径（想错就返工）**：

1. **`W̄/W ≡ 1.0000` 可能是取样方案的必然结果，不是笔误。**
   若方案是"10 片全部溶解定容到 100 mL、每份取 10.00 mL"，则
   `取 10.00 mL 相当的供试品量 W = W总 × 10/100 = W̄`，于是 `W = W̄`。
   ⚠️ 若误把 `W` 当作"10 片总重"套公式，结果**恰好偏低 10 倍**。
2. **碱滴定液的浓度会被空白试验完全抵消**，不进入计算式：

```
样品：n(药物) = n(碱加入) − 2n(酸样品)
空白：n(碱加入) = 2n(酸空白)
相减：n(药物) = 2·c(酸)·(V⁰ − Vˢ)      ← c(碱) 与加入体积被消掉
```

所以要报的不是"碱标了多少浓度"，而是**碱是否确实过量**（过量率）与**空白诊断**。

**敏感度分析**（讨论章必写）：`V⁰ / Vˢ 每偏差 1.00 mL → 含量变化多少个百分点`。
这个数直接说明单份测定的结论有多脆弱。

## 6. 方法学考察五项

| 项目 | 做法 | 指标 | 判据 |
|---|---|---|---|
| **线性关系** | 5 个浓度/进样量水平 | 回归方程 + **r** | `r > 0.999` |
| **精密度** | 同一对照液连续进样 6 针 | 峰面积 **RSD** | `RSD < 2%` |
| **稳定性** | 供试液 0 / 0.5 / 1 / 2 / 4 h | 峰面积 **RSD** | `RSD < 2%` |
| **重复性** | 平行制备 6 份供试液 | 含量 **RSD** | `RSD < 2%` |
| **含量测定** | 与重复性共用数据 | 占标示量 % | 依品种限度（常见 93.0%~107.0%） |

实现要点：

- 每项返回一个 dict：`{mean, s, rsd, n, pass}`，`pass = 指标 < 判据`
- 汇总表由这些 dict 拼出，`n_pass / n_total` 直接统计
- **含量 RSD 与重复性 RSD 同源**（共用数据），不要算两遍给出两个值

## 7. ★ 数据一致性诊断（含量明显偏离时必做）

当含量算出明显不合理（例如 40% 而不是接近 100%），**先诊断再下结论**：

```
① 峰面积比：A样 / A对                       若溶液确为理论浓度，应接近 100%
② 折算浓度：C样 = C对 × A样/A对              与 C理 比较
③ 应有峰面积：A应有 = A对 × C理 / C对         与实测比较
④ 三组横向比：对照品精密度 / 供试品重复性 / 供试品稳定性 各占对照品的百分之几
⑤ 敏感度：峰面积比每变动 1% → 含量变动多少百分点
```

**结论写法**：不要只说"不符合规定"，要说清——

> "按现有记录计算为 **××%（不符合规定）**；但供试品平均峰面积仅为对照品的 **××%**，
> 疑称样量 / 定容体积 / 进样体积记录之间存在不一致，**该结果不能代表样品真实含量**。"

再列出复核路径（核对原始记录、重配溶液、复测）。

> ⚠️ 诊断的目的是**说明数据可不可信**，不是为改数找理由。
> 诊断之后仍然照原样报，不许悄悄调到合格区间。

## 8. 正交设计与方差分析

```
CT  = (Σy)² / n                      校正项
SS_T = Σy² − CT                      总离差平方和
SS_因素 = (K₁² + K₂² + K₃²)/3 − CT    每水平下有 3 个试验点，故除以 3
SS_e(扣减) = SS_T − ΣSS_因素
MS = SS / df，df_因素 = 水平数 − 1
F  = MS_因素 / MS_误差
```

**★ 误差项怎么选（这一步决定结论对不对）**：

- **有组内重复**（每点测 3 次）→ 用**纯误差**：`SS纯 = Σ组内 Σ(x−x̄)²`，`df = 9×2 = 18`
- **无组内重复**（如综合评分，每处方只有 1 个值）→ 用**合并误差**：
  `MS_e = (SS_e扣减 + SS_最小因素) / 4`，`df = 4`
- ⚠️ **L₉(3³) 是饱和表**：响应取组内平均后，扣减残差理论上 = 0，
  拿它当误差项会让 `MS_e → 0`、F 值爆炸或 `#DIV/0!`。
- ⚠️ 只把"最小因素 / 2"当误差（`df = 2`）是**错的**——被并入的因素 F 恒等于 1，逻辑自相矛盾。

临界值（查表或 `scipy.stats.f.ppf(0.95, 2, df2)`）：

| 分母自由度 | F₀.₀₅ | F₀.₀₁ |
|---|---|---|
| df = 18 | 3.5546 | 6.0129 |
| df = 4 | 6.9443 | 18.0000 |

标记 `*`（显著）/ `**`（极显著）/ `ns`（不显著）。
**整体表述与逐因素标记要分开写**：整体可写"三因素均显著"，
正文必须写清 `A** B** C*`，不可笼统写成"三因素极显著"。

> 检验功效低（df 小）时判不出显著 ≠ 无影响，应写"以现有数据量无法证明有影响"。

## 9. 异常值的三种口径（并列呈现）

遇到离群点（例如某时间点峰面积是其余点的 10 倍）：

| 口径 | 用法 |
|---|---|
| **原记录** | 照录，给出原始 RSD |
| **按复核值**（疑多写一位） | 给出复核后 RSD，说明推测依据 |
| **剔除该点** | 给出剔除后 n 与 RSD，**判定以这个为准**并在正文写明 n 已减少 |

三个口径**并列**（工作簿三列 + 报告一段说明），由读者判断。
同理：保留时间漂移 → 同时给出"仅取一致的前 n 份"的口径。

> **不编造未测数据**；剔除后必须写明 n 的变化。

## 10. 判定与表述规范

- 单组分：`符合规定` / `不符合规定`（不要与"合格/不合格"混用）
- 多组分：先给各组分判定，再给总体判定；总体以**平均值**为准并附单份超限说明
- 方法学：`通过` / `未通过`，并给出 `n_pass / n_total`
- 判定文字**由限度常量与布尔量推导**，不要在正文里写死"符合规定"
- 判定与限度区间必须同时出现在正文（只写"符合规定"而不给限度，读者无法核对）
