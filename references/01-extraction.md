# 01　从课件与原始记录提取实验内容

> 这一步做砸，后面全白做——口径错了，脚本跑得再顺也是错的数字。
> 本文件是 Step 2 的操作手册：**提取什么、提到哪、缺了怎么办、怎么自检**。

---

## 1. 源文件有哪几类，各自给什么

| 源文件 | 提供什么 | 提取产物 |
|---|---|---|
| **课件截图 / PPT** | 实验目的、原理、方法步骤、计算公式、限度、思考题、注意事项 | 报告一/二/四/六章 + `_data.py` 口径常量 |
| **讲义 / 实验指导 PDF** | 同上，但更完整（含色谱条件、试液配制、方法学判据） | 同上 |
| **仪器谱图**（色谱工作站、光谱） | 峰结果表：保留时间、峰面积、峰高、主峰占比 | `_data.py` 的实测数组 |
| **手写记录 / 记录条** | 本组实测读数、称量、波长选择、操作者 | `_data.py` 的原始记录字典 |
| **实物照片**（比浊管、比色管、TLC 板） | 观察结果（谁更深） | 观察结果布尔量 + 描述串 |

**优先级：讲义 > 课件 > 手写记录。**
三者冲突时按此顺序取口径，但**冲突必须留痕**——写进报告的一条批注，说明"以课件为准，
手写记录处为笔误，不影响结果"。不要默默改掉。

## 2. 归集与重命名

```
01_source/
├── slides/          01_实验标题.jpg
│                    02_实验目的.jpg
│                    03_实验原理1-处方与结构式.jpg
│                    04_实验原理2-测定原理.jpg
│                    ...
│                    10_数据处理与含量计算.jpg
│                    11_思考题与注意事项.jpg
├── results/         01_吸光度记录.jpg
│                    02_滴定记录.jpg
└── spectra/         线性4ul.JPG、8ul.JPG、12ul.JPG、16ul.JPG、20ul.JPG
```

规则：

1. **编号 = 课件顺序**，两位数字前缀 + 中文短名说明这张图讲什么。
2. 一张图讲不完的拆多张，用 `03_实验原理1-…`、`04_实验原理2-…` 区分。
3. 谱图按**实验变量**命名（`线性4ul.JPG` 比 `IMG_0042.JPG` 有用得多）。
4. 源文件目录**只读**：不在里面产出任何东西。

## 3. 六问提取法

逐张读图，每张回答下面六个问题。答案直接落到 `README` 的口径表与 `_data.py` 输入区。

### Q1　目的：为什么要做这个实验

课件一般给 1~3 条，动词固定为 **掌握 / 熟悉 / 了解**。**照抄原句式，不要发挥**：

```
1. 掌握××片中××的含量测定方法。
2. 熟悉××法的操作要点与计算。
3. 了解方法学考察的各项判据及其意义。
```

若课件只给标题不给条目，按「对象 + 方法 + 技能」三要素补成 2~3 条，
并在 README 注明"目的条目由课件标题归纳"。

### Q2　原理：凭什么能用这个方法定量

必须提取出三样东西，缺一样原理章就写不实：

| 要素 | 问什么 | 例（双波长法） |
|---|---|---|
| **化学/物理依据** | 被测物有什么性质可用？ | 两组分紫外吸收光谱重叠 |
| **干扰怎么排除** | 为什么共存组分不影响？ | 选干扰组分的等吸收点，使其 ΔA = 0 |
| **定量关系式** | 信号与浓度是什么关系？ | ΔA = ΔE·C·l，与浓度成正比 |

原理章的标准写法：**先说困难（为什么不能直接测）→ 再说办法（本法怎么绕开）→ 最后给公式**。

### Q3　仪器与试剂

提取：仪器名称（型号/规格）、试剂与试液（含浓度）、试液配制方法。

> **粒度建议**：仪器与试剂用**文字列举**而不用表格——
> 这是实验报告批改中最常被要求改的一处（表格占版面、信息密度低）。
> 写成「××计（型号）、分析天平（0.1 mg）、量瓶（100 mL）……」即可。

### Q4　方法步骤：所有进入公式的量，一个都不能漏

这是**最容易漏**的一问。凡进入计算式的量，必须全部抓出来：

| 必取项 | 例 |
|---|---|
| 取样方案 | 取本品 10 片，精密称定，研细 |
| 称取量与"约相当于" | 精密称取约相当于主药 25 mg 的粉末 |
| 定容体积 | 置 100 mL 量瓶，定容 |
| 稀释倍数 | 精密量取 2 mL → 100 mL（×50） |
| 反应/平衡条件 | 水浴 15 min、暗处放置 5 min、振摇使溶解 |
| 测定条件 | 检测波长、流动相比例、柱温、进样量 |
| 对照品处理 | 105 ℃ 干燥至恒重，按原料药含量折算 |
| 平行份数 | 平行制备 6 份 / 平行 2 份、空白 1 份 |

方法章写法：**按实际操作顺序编号，每步写清"取多少 → 加什么 → 定容到多少 → 放多久 → 怎么读"**。

### Q5　数据处理：公式 + 符号表 + 限度

三件套，缺一不可：

1. **计算公式**（原式照抄，不要提前化简——留痕便于核对）
2. **符号表**（每个符号 = 什么、单位是什么）
3. **限度**（药典或课件原文：含量 93.0%~107.0%、氯化物不得过 0.010%、重金属不得过百万分之五）

> 限度**必须引原文**，不要自己估。
> 同时把限度写成 `_data.py` 的 `*_LOWER` / `*_UPPER` 常量，判定由它们推导。

### Q6　思考题与注意事项

思考题逐条照抄，答案结合**本组数据**作答（不要写成教科书通用答案）。
注意事项（暗处放置、黑色背景比浊、弃初滤液、平行操作）**并入原理或方法章**，
一般不建议单列一章——它是操作细节，不是独立章节。

## 4. 提取结果落三处

```
课件/讲义 ──┬─→ README「实验口径」        人读：口径清单 + 本组数据 + 口径判断
            ├─→ 02_scripts/_data.py 输入区   机读：口径常量 + 原始记录
            └─→ 02_scripts/build_docx.py     正文：一/二/三/四/六章段落
```

**三处必须同源同步**。改口径先改 `_data.py`，再重跑，不要反过来改正文。

## 5. 原始记录转录规则

1. **逐格转录，保留划改**：划改处取**改后值**，并在表注里交代（"① 原记录 0.022，划改为 0.021"）。
2. **谱图只取有效行**：色谱"峰结果表"里只取目标峰那一行，其余峰不录入、不讨论
   （除非本次实验的目的就是杂质分析）。
3. **异常值保留原样**：疑似多写一位（`4523100` vs `452310`）、保留时间明显漂移——
   **照录**，另设 `*_SUSPECT_INDEX` / `*_CORRECTED_*` 常量做多口径并列，**不改原值**。
4. **操作者/批次标记留痕**：`TAGS = {"s1": "甲", "s2": "乙"}`，正文写"第一份（甲）"。
5. **转录稿以原图为准**：若先 OCR 或手抄成 md 再录入，**原图优先**，转录稿只作参照。
6. **单位统一在输入区**：mg 还是 g、μg 还是 mg，在常量名里写清楚（`W_SAMPLE_G`、`C_STD_MG_ML`），
   换算只在派生量里做一次。

## 6. 三类"必须问人"的缺口

| 缺口类型 | 例 | 处理 |
|---|---|---|
| **课件没有的本组实测值** | 观察结果（谁更浑浊）、供试品称取量、平均片重 | 问用户；不给就留「（待填）」，**不代填** |
| **口径冲突** | 手写记录与课件符号相反、讲义与课件取样方案不同 | 按讲义/课件口径，报告加批注说明 |
| **数据异常** | 峰面积量级差 10 倍、平行两份相差 20%+ | 保留原样 + 多口径并列 + 讨论章给复核路径 |

> 留「（待填）」是**正确做法**，不是偷懒。
> 把待填项做成布尔量（`DATA_OBS_FILLED`），用户拿到实测值后改一个值重跑即可全文替换。
