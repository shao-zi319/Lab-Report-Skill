## 例 1　限量检查（氯化物，比浊法）

**口径**：取供试品 0.30 g 加水溶解（B 管）；标准液 3.0 mL × 10 μg/mL（A 管）；
两管各加稀硝酸 5 mL、硝酸银试液 0.5 mL，加水至 25 mL，暗处放置 5 min，黑色背景比浊。
限度：不得过 0.010%。

**限量计算**（与实测无关，确定性计算）：

```
L = V·c / S × 100%
  = 3.0 mL × 10 μg/mL ÷ (0.30 g × 10⁶ μg/g) × 100%
  = 30 μg ÷ 300000 μg × 100%
  = 0.010%
```

**观察结果与判定**：A 管（对照）浊度 ＞ B 管（供试品）⟹ B 不深于 A ⟹ **符合规定**。

**`_data.py` 写法**：

```python
V_STD_ML, C_STD_UG_ML, S_G = 3.0, 10.0, 0.30
LIMIT_PCT = 0.010
OBS_PASS = True            # 供试品不深于对照管
L = V_STD_ML * C_STD_UG_ML / (S_G * 1e6) * 100     # 0.01
PASS = OBS_PASS and L <= LIMIT_PCT
```

## 例 2　HPLC 外标法 + 方法学五项

**口径**：对照品 0.5058 mg/mL；供试品平行 6 份，每份称样 0.2742 g
（约相当于主药 25 mg）→ 50 mL 量瓶 → `C理 = 25/50 = 0.500 mg/mL`；
标示量 30 mg/片；限度 93.0%~107.0%。

### ① 线性关系（5 个进样量）

| 进样量 V/μL | 峰面积 A | 回归值 | 相对偏差 |
|---|---|---|---|
| 4 | 205 600 | 210 760 | −2.45% |
| 8 | 412 300 | 412 920 | −0.15% |
| 12 | 622 400 | 615 080 | +1.19% |
| 16 | 825 100 | 817 240 | +0.96% |
| 20 | 1 010 000 | 1 019 400 | −0.92% |

```
A = 50540·V + 8600 ,  r = 0.99972 ,  r² = 0.99943
判据 r > 0.999 → 通过
```

> 4 μL 点偏差 2.45% 最大，提示低进样量端误差偏大——讨论章可提一句
> "低进样量受进样精度影响较大"，但**不改数据**。

### ② 精密度（同一对照液连续 6 针）

峰面积：512 340、519 870、508 110、521 450、515 600、517 230

```
均值 = 515 766.67   s = 4933.0   RSD = 0.96%   < 2%  → 通过
```

`A对 = 515 766.67`（外标法用这个值）

### ③ 稳定性（供试液 0 / 0.5 / 1 / 2 / 4 h）

峰面积：489 120、490 350、488 670、491 240、487 960

```
均值 = 489 468   s = 1318.1   RSD = 0.27%   < 2%  → 通过
```

### ④ 重复性（平行 6 份）

峰面积：487 210、491 340、488 760、490 150、489 020、490 270

```
均值 = 489 458.33   s = 1443.1   RSD = 0.29%   < 2%  → 通过
```

### ⑤ 含量测定（与重复性共用数据）

```
C样 = C对 × A样/A对 = 0.5058 × 489458.33/515766.67 = 0.4800 mg/mL
m   = C样 × V = 0.4800 × 50 = 24.00 mg
含量 = m ÷ 相当量 × 100% = 24.00 / 25 × 100% = 96.00%
每片 = 96.00% × 30 mg = 28.80 mg
判定：93.0%~107.0% → 96.00% 符合规定
```

### 汇总

| 项目 | 指标 | 判据 | 判定 |
|---|---|---|---|
| 线性关系 | r = 0.99972 | r > 0.999 | 通过 |
| 精密度 | RSD = 0.96% | RSD < 2% | 通过 |
| 稳定性 | RSD = 0.27% | RSD < 2% | 通过 |
| 重复性 | RSD = 0.29% | RSD < 2% | 通过 |
| 含量测定 | 96.00% | 93.0%~107.0% | 符合规定 |

**5/5 达标。**

### 反向演练：如果含量算出 87% 怎么办

把上面的 A样 换成 445 188（其余不变）：

```
C样 = 0.5058 × 445188/515766.67 = 0.4366 mg/mL
含量 = 0.4366 × 50 / 25 × 100% = 87.3%   → 不符合规定
```

先别急着写结论，做**一致性诊断**：

```
A样/A对 = 445188/515767 = 86.3%          （若溶液确为 0.500 mg/mL，应 ≈ 98.8%）
应有峰面积 = 515767 × 0.500/0.5058 = 509 780
实测 445 188 → 仅为应有值的 87.3%
```

结论写法：**"按现有记录计算为 87.3%（不符合规定）；但供试品峰面积仅为应有值的 87.3%，
提示供试品溶液浓度偏低（称样、定容或稀释环节），建议核对原始记录后复测。"**

## 例 3　双波长等吸收点法（复方制剂两组分）

**口径**（波长为示例值，实际以你的品种与仪器扫描结果为准）：
λ2 = 257.0 nm（测定波长）、λ1 = 304.7 nm（另一组分的等吸收点）；
对照品 m_R = 50.00 mg；W̄ = 0.5800 g/片；W = 0.0725 g；标示量 400 mg/片；限度 90.0%~110.0%。

| 溶液 | A(λ2) | A(λ1) | ΔA |
|---|---|---|---|
| 对照品 | 0.648 | 0.002 | **0.646** |
| 供试品① | 0.640 | 0.021 | **0.619** |
| 供试品② | 0.633 | 0.019 | **0.614** |

```
含量(mg/片) = ΔA_X × m_R × W̄ / (ΔA_R × W)

① = 0.619 × 50.00 × 0.5800 / (0.646 × 0.0725) = 383.3 mg/片  → 95.8%
② = 0.614 × 50.00 × 0.5800 / (0.646 × 0.0725) = 380.2 mg/片  → 95.0%

平均 = 381.7 mg/片（95.4%）  相对平均偏差 = |383.3−380.2|/381.7 × 100% = 0.81%
判定：360~440 mg/片 → 符合规定
```

## 例 4　两步滴定法（酯类）

**口径**：10 片全部溶解定容 100 mL，精密量取 10.00 mL；加入碱滴定液 40.00 mL，
水浴 15 min 后放冷，用酸滴定液回滴；空白同法。标示量 0.3 g/片。

**关键前提**：因"10 片全溶 → 取 1/10"，`W = W总 × 10/100 = W̄`，
故 `W̄/W = 1.0000`——**这是取样方案的必然结果，不是笔误**。

```
F(酸) = c(酸)/0.05 = 0.05333/0.05 = 1.0666
T     = 2 × 0.05 mmol/mL × 180.16 mg/mmol = 18.02 mg/mL

V⁰（空白）= 36.20 mL，Vˢ（样品）= 20.90 mL  →  ΔV = 15.30 mL

m   = ΔV × F × T = 15.30 × 1.0666 × 18.02 = 294.07 mg
含量 = 294.07 / 300 × 100% = 98.02%   → 93.0%~107.0% 符合规定
```

**空白诊断**（讨论章写）：

```
加入碱 40.00 mL × 0.10 mol/L = 4.000 mmol
理论空白体积（碱全部由酸回滴）= 4.000 / 2 / 0.05 = 40.00 mL
实测 36.20 mL → 偏少 3.80 mL，相当于 0.38 mmol 碱被空白"吃掉"
敏感度：ΔV 每偏差 1.00 mL → 含量变化 1.0666×18.02/300×100% = 6.41 个百分点
```

> 敏感度这个数说明：**单份测定不足以支撑结论**，应补做平行份并复核空白。

## 例 5　正交设计与方差分析（3 因素 3 水平）

**设计**：L₉(3³)，9 个试验点，每点 3 次重复；因素 A/B/C 各 3 水平。

```
CT   = (Σy)²/n
SS_T = Σy² − CT
SS_A = (K₁² + K₂² + K₃²)/3 − CT          K = 该水平下响应之和
SS_e = SS_T − SS_A − SS_B − SS_C           （饱和表，≈0，不可用作误差）
SS纯 = Σ组内 Σ(x − x̄组)²                    df = 9 × (3−1) = 18
MS   = SS/df，F = MS因素 / MS纯
```

**误差项选择**：

| 响应 | 有无组内重复 | 误差项 | df |
|---|---|---|---|
| 单项指标（每点测 3 次） | 有 | 纯误差 | 18 |
| 综合评分（每点只有 1 个值） | 无 | 合并误差 `(SS_e + SS_最小因素)/4` | 4 |

判定：`F₀.₀₅(2,18) = 3.5546`、`F₀.₀₁(2,18) = 6.0129`；`F₀.₀₅(2,4) = 6.9443`。

> ⚠️ 若某响应判为 `ns`，写"以现有数据量无法证明该因素有影响"，
> 不要写"该因素无影响"——两者不是一回事。
